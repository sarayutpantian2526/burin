# BURIN

Board for Understanding, Reasoning, Inquiry and Notes

คู่มือติดตั้ง BURIN ให้ใช้บน iPad ทีวี และคอมพิวเตอร์ โดยซิงก์สมุดข้ามเครื่องผ่าน Supabase ทำตามลำดับ ภาค ก ถึง ง ภาค ก ถึง ค ทำบนคอมพิวเตอร์ครั้งเดียว

## ไฟล์ในชุด

| ไฟล์ | หน้าที่ |
|---|---|
| index.html | ตัวแอป |
| config.js | ค่าการเชื่อม Supabase ของอาจารย์ |
| setup.sql | คำสั่งสร้างฐานข้อมูล ใช้ในภาค ก |
| vendor/supabase.js | ตัวเชื่อม Supabase |
| sw.js, manifest.webmanifest, icon-*.png | ทำให้ติดตั้งเป็นแอปและเปิดแบบออฟไลน์ได้ |

## ภาค ก ตั้งค่า Supabase

1. เข้า supabase.com ด้วยบัญชีที่ไม่เกี่ยวกับองค์กรที่มีใบแจ้งหนี้ค้าง
2. สร้างองค์กร (New organization) ชื่อ `BURIN` แบบ Personal แผน Free
3. สร้างโปรเจกต์ (New project) ชื่อ `burin` กด Generate a password แล้วเก็บรหัสไว้ เลือก Region เป็น Southeast Asia (Singapore) แล้วรอ 1 ถึง 2 นาที
4. สร้างฐานข้อมูล
   1. เมนูซ้ายเลือก SQL Editor
   2. เปิดไฟล์ setup.sql ด้วย Notepad หรือ TextEdit คัดลอกทั้งหมดไปวาง
   3. กด Run ต้องขึ้นว่า Success. No rows returned
5. ตั้งค่าการเข้าระบบ
   1. เมนูซ้ายเลือก Authentication แล้วเลือก Sign In / Providers
   2. กดที่ Email แล้วปิด Confirm email กด Save (สมัครแล้วใช้ได้ทันที ไม่ต้องรออีเมลยืนยัน)
6. คัดลอกค่าสองค่า
   1. เมนูซ้ายล่างเลือก Project Settings แล้วเลือก API Keys
   2. Publishable key ขึ้นต้นด้วย `sb_publishable_` (ถ้าไม่มีให้ใช้ anon key ในแท็บ Legacy API Keys)
   3. Project URL อยู่ในหน้า Data API หรือปุ่ม Connect ด้านบน หน้าตาแบบ `https://xxxx.supabase.co`
   4. ห้ามใช้ Secret key หรือ service_role ในแอปเด็ดขาด

## ภาค ข ใส่ค่าลงใน config.js

1. เปิด config.js ด้วย Notepad หรือ TextEdit
2. ใส่ค่าในเครื่องหมายคำพูด

```js
window.BURIN_CONFIG = {
  supabaseUrl: 'https://xxxx.supabase.co',
  supabaseKey: 'sb_publishable_xxxxxxxx'
};
```

3. บันทึกไฟล์

## ภาค ค นำขึ้นเว็บด้วย GitHub Pages

1. สมัครหรือเข้าระบบที่ github.com
2. กด + มุมขวาบน เลือก New repository ตั้งชื่อ `burin` เลือก Public แล้วกด Create repository
3. คลิก uploading an existing file
4. เปิดโฟลเดอร์ burin ในคอมพิวเตอร์ เลือกทุกอย่างข้างใน (Ctrl+A หรือ Command+A) รวมโฟลเดอร์ vendor แล้วลากไปวางในหน้าเว็บ
5. รอรายชื่อไฟล์ขึ้นครบ แล้วกด Commit changes
6. ไปที่ Settings แล้วเลือก Pages ตั้ง Branch เป็น `main` และ `/ (root)` กด Save
7. รอ 1 ถึง 2 นาที รีเฟรช จะได้ลิงก์ เช่น `https://ชื่อบัญชี.github.io/burin/`

ถ้าเปิดแล้วขึ้น 404 ให้ตรวจว่า index.html อยู่ชั้นแรกของ repository ไม่ได้อยู่ในโฟลเดอร์ burin อีกชั้น

## ภาค ง เข้าใช้บนแต่ละเครื่อง

### เครื่องแรก (คอมพิวเตอร์)

1. เปิดลิงก์ จะมีหน้าต่าง "เข้าสู่ระบบ BURIN"
2. ใส่อีเมลและตั้งรหัสผ่านอย่างน้อย 8 ตัว แล้วกด "สร้างบัญชีใหม่" (ทำครั้งเดียว)
3. กลับไปที่ Supabase เมนู Authentication แล้วเลือก Sign In / Providers ปิด Allow new users to sign up กด Save เพื่อไม่ให้คนอื่นสมัครใช้พื้นที่ของอาจารย์

### iPad

1. เปิดลิงก์ด้วย Safari
2. กดปุ่มแชร์ แล้วเลือก "เพิ่มไปยังหน้าจอโฮม" กด "เพิ่ม"
3. เปิดแอปจากไอคอน BURIN แล้วกด "เข้าสู่ระบบ" ด้วยอีเมลและรหัสผ่านเดิม
4. ต่อจากนี้เปิดจากไอคอนเสมอ

### ทีวีทัชสกรีน

เปิดลิงก์ด้วย Chrome เลือก "ติดตั้งแอป" หรือ "เพิ่มลงในหน้าจอหลัก" แล้วเข้าระบบด้วยบัญชีเดิม

### ย้ายสมุดที่เขียนไว้ก่อนต่อคลาวด์

ถ้าเครื่องไหนมีสมุดที่เขียนไว้ก่อนเข้าระบบ ให้เปิดเมนู (โลโก้ B) หัวข้อ "ซิงก์ข้ามเครื่อง" แล้วกด "ย้ายสมุดในเครื่องขึ้นคลาวด์"

## จอผู้ชม (สำหรับแชร์หน้าจอ)

บนเครื่องที่ใช้แชร์จอ เปิดลิงก์ที่ต่อท้ายด้วย `#present` แล้วเข้าระบบด้วยบัญชีเดิม แชร์เฉพาะหน้าต่างนี้ ผู้ชมจะเห็นเฉพาะกระดาษ ลายมือ และเลเซอร์ที่เขียนจาก iPad ทันที และเปลี่ยนหน้าตาม iPad แตะสามครั้งเพื่อออก

## ผู้ช่วย AI

ตั้งค่าที่เมนู หัวข้อ "ผู้ช่วย AI" เลือกได้ทีละงาน (อ่านลายมือ สร้างโจทย์ วาดรูปใหม่)

| แหล่ง AI | ค่าใช้จ่าย | หมายเหตุ |
|---|---|---|
| AI ในเครื่อง (Ollama, LM Studio) | ฟรี | ต้องมีคอมพิวเตอร์ที่แรงพอ อ่านลายมือไทยได้ด้อยกว่าโมเดลบนคลาวด์ |
| คีย์ API ของตัวเอง (Claude, OpenAI, Gemini, Typhoon) | จ่ายตามที่ใช้ | คีย์เก็บเฉพาะในเครื่องนั้น |

ตั้ง Ollama: ติดตั้งจาก ollama.com สั่ง `ollama pull qwen2.5vl:7b` ตั้งค่า `OLLAMA_ORIGINS=*` แล้วเปิด Ollama ใหม่ ในแอปกดปุ่ม Ollama ใส่ชื่อโมเดล แล้วกดทดสอบ หน้าเว็บ https เรียก AI บนคอมพิวเตอร์อื่นผ่าน http ไม่ได้ ถ้าจะให้ iPad ใช้ AI บนคอมพิวเตอร์ในห้อง ต้องเปิดแอปจากคอมพิวเตอร์เครื่องนั้น

## ทำงานตอนเน็ตหลุด

เขียนต่อได้ตามปกติ ป้ายมุมบนจะขึ้นว่า "ออฟไลน์ จะซิงก์เมื่อต่อเน็ต" เมื่อเน็ตกลับมา แอปจะส่งงานขึ้นคลาวด์เอง และป้ายเปลี่ยนเป็น "ซิงก์แล้ว"

## อัปเดตเวอร์ชันใหม่

อัปโหลด index.html ใหม่ทับใน repository เดิม (Add file แล้วเลือก Upload files) แล้วปิดและเปิดแอปใหม่หนึ่งถึงสองครั้ง สมุดบนคลาวด์อยู่ครบ ไม่ต้องอัปโหลด config.js ซ้ำ

## ขีดจำกัดของแผนฟรี

Supabase แผนฟรีให้ฐานข้อมูล 500 MB และที่เก็บไฟล์ 1 GB พอสำหรับสมุดลายมือหลายพันหน้า วิดีโอกินพื้นที่มากที่สุด แอปจำกัดวิดีโอละไม่เกิน 20 MB โปรเจกต์ฟรีที่ไม่มีการใช้งาน 7 วันจะถูกพักไว้ เข้าไปกด Restore ในหน้า Supabase ได้ ข้อมูลไม่หาย

## ก่อนวางขายจริง (ขายให้บุคคลผ่าน App Store และ Play Store ไม่ขายให้โรงเรียน)
ตอนนี้ใช้การเข้าระบบด้วยอีเมลและรหัสผ่านผ่าน Supabase ไปก่อน ก่อนขายต้องทำให้ครบ
1. ลบบัญชีได้เองในแอป และมีหน้าเว็บสำหรับขอลบบัญชี (Apple และ Google บังคับ)
2. ปุ่มลืมรหัสผ่าน
3. ส่งอีเมลยืนยันผ่านผู้ให้บริการอีเมลของเราเอง เช่น Resend หรือ Brevo (ระบบอีเมลในตัวของ Supabase จำกัดจำนวนต่ำมาก)
4. นโยบายความเป็นส่วนตัวภาษาไทยและอังกฤษ ตาม PDPA
5. ถ้าเพิ่มเข้าระบบด้วย Google ต้องมี Sign in with Apple ด้วย
6. อัปเกรด Supabase เป็นแบบเสียเงิน (แบบฟรีพักโปรเจกต์เองเมื่อไม่มีคนใช้ราว 7 วัน)
7. ผูกระบบบัญชีกับโดเมนของ Burin เอง เพราะบางเครือข่ายบล็อก supabase.co
