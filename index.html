จอสำหรับผู้ชม

ใช้ตอนแชร์หน้าจอหรือฉายขึ้นทีวี ผู้ชมจะเห็นเฉพาะกระดาษและสิ่งที่อยู่บนกระดาษ ไม่เห็นแถบเครื่องมือ จอผู้ชมจะเปลี่ยนหน้าและเลื่อนตามเครื่องที่เขียน เห็นลายมือและเลเซอร์ทันที

เปิดแอปนี้อีกหน้าต่างหนึ่งหรือบนอีกเครื่อง แล้วกดปุ่มด้านล่าง จากนั้นแชร์เฉพาะหน้าต่างนั้นในโปรแกรมประชุม ออกจากจอผู้ชมได้ด้วยการแตะจอสามครั้งติดกัน

ซิงก์ข้ามเครื่อง

ตั้งค่าการเชื่อม Supabaseใส่ครั้งเดียวต่อเครื่อง หรือใส่ไว้ในไฟล์ config.js ให้ทุกเครื่องใช้ร่วมกัน

ผู้ช่วย AI

AI ในเครื่องของคุณOllama หรือ LM Studio ใช้ฟรี ข้อมูลไม่ออกนอกเครื่อง
โมเดลอ่านภาพได้ต้องเปิดไว้จึงจะอ่านลายมือและวาดรูปใหม่ได้ ใช้โมเดลที่มีคำว่า vl หรือ vision
ให้ AI ใช้เครื่องคิดเลขช่วยให้ตัวเลขในเฉลยถูกต้อง ปิดไว้ถ้าโมเดลไม่รองรับการเรียกเครื่องมือ
ติดตั้ง Ollama บนคอมพิวเตอร์ แล้วสั่ง ollama pull qwen2.5vl:7b และตั้งค่า OLLAMA_ORIGINS=* ให้เบราว์เซอร์เรียกได้ ถ้าใช้จาก iPad ให้ใส่ที่อยู่ IP ของคอมพิวเตอร์แทน localhost และเปิดแอปผ่านคอมพิวเตอร์เครื่องเดียวกันนั้น โมเดลในเครื่องอ่านลายมือไทยได้ด้อยกว่าโมเดลบนคลาวด์
คีย์ API ของคุณเองจ่ายตามที่ใช้กับผู้ให้บริการโดยตรง
ตั้งค่าเพิ่มเติม ไม่ต้องแก้ก็ได้
ใช้คีย์นี้กับทุกเครื่องที่เข้าระบบบัญชีเดียวกันใส่ครั้งเดียว iPad คอมพิวเตอร์ และทีวีใช้ได้หมด คีย์เก็บในคลาวด์ของบัญชีนี้ คนอื่นอ่านไม่ได้ ถ้าปิด คีย์อยู่เฉพาะเครื่องนี้

การเขียนและจอ

นิ้ววาดได้ปิดไว้ นิ้วจะใช้เลื่อนและซูม ปากกาเขียนอย่างเดียว ระบบปิดให้เองเมื่อพบปากกา
วางฝ่ามือเพื่อลบสำหรับทีวีทัชสกรีนที่บอกขนาดพื้นที่สัมผัสได้
ลากค้างให้เป็นรูปทรงลากเส้นแล้วกดค้างไว้ครู่หนึ่ง จะได้เส้นตรง วงกลม วงรี สามเหลี่ยม หรือสี่เหลี่ยม เส้นตรงลากปรับปลายต่อได้ก่อนยกปากกา
ขีดทับเพื่อลบขีดไปมาทับลายมือหรือกล่องข้อความด้วยปากกา ระบบจะลบส่วนนั้นให้ ภาพสปริงที่วาดบนที่ว่างไม่ถูกลบ
โหมดจอใหญ่สำหรับทีวีทัชสกรีน ปุ่มใหญ่และอยู่ด้านล่าง เอื้อมถึงขณะยืนสอน

เชื่อมต่อ AI ของคุณ

การแปลงลายมือเป็นตัวพิมพ์และสมการ การสร้างโจทย์ และการวาดรูปใหม่ ใช้ AI ของผู้ใช้เอง Burin ไม่มี AI ของตัวเองและไม่เก็บค่าบริการ
ทางที่ง่ายที่สุด เข้าระบบแล้วกดอนุญาต ไม่ต้องคัดลอกคีย์ ใช้บัญชี OpenRouter ซึ่งเป็นช่องทางเดียวที่เข้าถึง AI หลายเจ้า เช่น Gemini, Claude, GPT สมัครด้วยบัญชี Google ได้ บางโมเดลใช้ฟรีแบบจำกัดจำนวนครั้ง โมเดลที่อ่านลายมือได้ดีส่วนใหญ่ต้องเติมเครดิตในบัญชี OpenRouter ก่อน
หรือวางคีย์ API ที่มีอยู่ Gemini ใช้ฟรีได้ หรือคีย์ Claude, OpenAI, Typhoon
  1. ขอคีย์ Gemini ฟรีที่ aistudio.google.com/apikey กด Create API key แล้วคัดลอก
  2. วางคีย์ในช่องด้านล่าง แล้วกด เชื่อมต่อ ระบบดูจากคีย์ว่าเป็นของเจ้าไหนและเลือกโมเดลให้เอง
เมื่อเข้าระบบคลาวด์ของ Burin เชื่อมต่อครั้งเดียวแล้วใช้ได้ทุกเครื่องของบัญชีนี้ (ปิดได้ในเมนู หัวข้อคีย์ API) ถ้าเปิด Burin ใน claude.ai ระบบใช้ Claude ของคุณได้ทันทีโดยไม่ต้องเชื่อมต่อ

การทดลองและตารางผล

เลือกแบบตั้งต้น แล้วแก้ข้อมูลในการ์ดบนหน้ากระดาษได้ทั้งหมด กราฟใช้วิธีกำลังสองน้อยที่สุด ความไม่แน่นอนของความชันคำนวณจากการกระจายของจุดรอบเส้นตรง ผลที่หาจากความชันคิดการแพร่ความคลาดเคลื่อนให้ด้วย

แบบจำลองการทดลอง

แตะเพื่อวางลงหน้ากระดาษ ทุกแบบจำลองคำนวณตามสมการฟิสิกส์จริง ปรับค่าได้ด้วยแถบเลื่อน เวกเตอร์ความเร็วเป็นสีน้ำเงิน แรงเป็นสีส้ม
